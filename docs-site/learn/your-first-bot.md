# Your first bot

On first launch, VelarixBot seeds one bot named **Chief of Staff** and opens its thread with a short onboarding card asking what you mostly want help with.

## Create a teammate

Press **+** in the sidebar. The create modal asks for a name, a role or personality line, a color, an avatar, and an engine + model. Engines that aren't installed or signed in appear dimmed with the reason (for example `` `gemini` CLI not found ``). The avatar starts as a generated face seeded from the bot; if an image provider key is configured (xAI, OpenAI, or OpenRouter) you can generate portrait candidates and pick one.

## Say hello

Type into the composer. The bot's turn streams live: text, tool calls, and — when a tool needs consent — an approval card with allow-once and always-allow options. Attach files with the paperclip; queue prompts while a turn runs and they deliver in order.

## Give it a computer

In the bot's settings, bind a computer: **local** to drive this machine, or a **Box** cloud desktop you can watch in the computer panel. The shared-computer toggle in App Settings gives every bot one desktop and one Chrome, so bots can see each other's files and logins there — enable it deliberately.

## Make it recurring

Anything the bot did well can become a routine (schedule + prompt) from the Routines panel, or teach it a skill by demonstrating a task once and saving the distilled steps.
