# Skills & teach-a-task

A taught skill is a reusable, named procedure a bot learned from you.

Start a teach session, demonstrate the task once (in chat, or on the bot's computer), and stop the session with a name. The harness distills the demonstration into a markdown skill — steps, context, and cautions — stored under the workspace and listed in the Skills panel.

Bots run their enabled skills on request ("do the invoice check") or on a schedule when a routine references the skill. Skills are plain markdown: open one, edit it, and the bot follows the edited version. Skills are enabled per bot, so a procedure taught to one specialist doesn't leak into every bot's toolkit.
